- WGS extrapolation inconsistent: 36 h (literature), 189.2 h (`06`, ×64,000 regions), 160,000 regions in `03`, 35.5 h in GPU summary, 14.1× "local observed". Pick one, label as estimate.
- GPU named inconsistently: T4 (summary json, fig3, notebook) vs A10G (README, sagemaker json). Speedup 48× vs 56.8×.
- Cohort size: README 198 patients; dashboard text 187 (`App.jsx:202,664`); `05` output 566. Dashboard "ClinVar benchmark N=243" vs README (CLIN_SIG only 586 populated, "too sparse"). Dashboard AUC/ClinVar come from generated files that are not in repo.

- README says "RF + XGBoost": the code uses sklearn `GradientBoostingClassifier`; XGBoost is never cross-validated (`xgb_auc = 0.0` hard-coded, line 291), only RF has CV metrics. README status table (AUC 0.987, PR-AUC 0.268) ≠ later section (0.258) ≠ files (AUC 0.989).
